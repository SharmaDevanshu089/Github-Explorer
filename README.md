# GitHub Explorer — a half-baked file explorer

Short version: this was supposed to be a GitHub-based file explorer. I lost motivation (it was a pet project). Still, it builds and runs — mostly to prove I started something.

Why this exists
- I wanted a desktop-ish GitHub file explorer. Then life happened and motivation... did not.
- Be warned: this is a prototype and not a polished app. It's funny because it was supposed to be serious.

Tech stack
- Frontend: React
- Backend/native: Rust
- Desktop wrapper: Tauri

Status
- Current build compiles. You can run the project, but expect rough edges.
- There is a project brief (see project brief file in repo) that contains the full idea and intended features.
- A prototype.html was included to inspect layout and size — open it in a browser to view the quick prototype.

How to run (very short)
1. Follow the repo's brief / README scripts (install dependencies, build with tauri dev/build).
2. Open prototype.html in a browser to view the static prototype and sizing.

Notes
- This is a pet project. I may return to it someday. Or not. Either way: enjoy the curiosity.

Contributions
- If you want to pick this up, feel free. Check the project brief for the intended direction.
